# page

> L2 | 父级：[项目地图](../AGENTS.md)

- `index.html`、`launch.js`：Magpie 官方桥接入口，在桌面打开回环服务，在网页版使用 Magpie 的服务代理。
- `view.html`、`client.js`：页面骨架、Magpie 主题消息和带本次启动凭证的状态读取及按钮请求。
- `i18n.js`：跟随 Magpie 语言，提供中英文界面、时间和简短操作反馈。成功提示自动收起，错误保留。
- `app.js`：展示 Magpie agy-cli 供应商名单与额度，保留会员、免费与套餐未知分组并折叠停用和不可用账号；优先显示 Gemini，再显示 GPT / Claude 的 5h / 7d 窗口，以及有有效读数的 Carbon 独立窗口、未知与过期状态。表头计数以主表实际账号为准，「仅会员」开关的选择在本机记住。工具栏汇总可见账号的额度补查、查询超时与登录续期失败，详情保留具体原因、受影响账号和历史读数时间。手动操作经同一页面服务提交，不改 Magpie 插件设置。
- 邮箱旁只在钥匙串回读确认后显示桌面保存勾号。CLI 标签和「仅 CLI」按钮默认收起，由工具栏一起切换，选择由本机页面服务保存。切换进度、待确认与失败反馈复用触发按钮的位置，点击异常反馈可看详情。刷新期间可切号，补查和查询超时在刷新按钮旁提示。
- `style.css`：页面随 Magpie 的显式主题绘制整页底色与提示、按钮，刷新、切换动效遵循减少动态效果设置；宽屏共用额度列位，窄屏使用额度圆盘和短时间，必要时按模型组重新排列，0% 空条与未知状态分开显示。
- `icon.svg`：侧边栏图标。
- `.runtime/state.js`：运行时生成的无凭据状态文件，已被 Git 忽略，不手工编辑或发布个人快照。升级时旧页面仍可通过原位置的静态脚本读取新快照。
