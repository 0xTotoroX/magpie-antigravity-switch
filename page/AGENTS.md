> L2 | 父级：[项目地图](../AGENTS.md)

- `index.html`：页面骨架和 Magpie bridge、经典脚本入口。
- `i18n.js`：跟随 Magpie 语言，提供中英文界面、日期与插件状态反馈。
- `app.js`：展示 Magpie agy-cli 供应商名单与额度，保留会员、免费与套餐未知分组并折叠停用和不可用账号；固定显示 GPT / Claude、Gemini 与 Argon 的 5h / 7d 窗口，以及实际返回的 Carbon 独立窗口、未知与过期状态，保留原始档位及桥接指令；页面沙箱自身保持零网络请求。
- 登录状态以账号行内标签呈现，可区分已登录的桌面端、待生效目标、CLI 与 Magpie 首选；CLI 状态显示新启动时读取的账号，使用共享登录时在「仅 CLI」提示中说明。
- `style.css`：页面嵌入时透出 Magpie 的底色，刷新图标遵循减少动态效果设置；宽屏共用额度列位，窄屏按模型组重新排列，0% 空条与未知状态分开显示。
- `icon.svg`：侧边栏图标。
- `state.js`：运行时生成的无凭据状态文件，已被 Git 忽略，不手工编辑或发布个人快照。
